## Projects

### 🦒 [Giraffle](https://github.com/GiraffeGraph/giraffle)

A **self-hosted knowledge editor** that combines block editing, wikilinks, backlinks, graph navigation, and canonical PostgreSQL storage.

- Block-based editor powered by Tiptap
- Wikilinks, backlinks, and interactive link graph
- PostgreSQL-backed canonical note and block storage
- Folder hierarchy, tags, templates, publishing, and public note pages
- Self-hosted with Docker Compose

**Stack:** Next.js 16 · React 19 · Prisma 7 · PostgreSQL 16 · Docker

---

### 🧠 [GiraffeGraph Core](https://github.com/GiraffeGraph/giraffegraph-core)

A **general-purpose knowledge graph platform** that transforms raw, unstructured data into a structured, verifiable, and incrementally growing knowledge graph.

- Schema-driven entity and relationship extraction
- AI-assisted candidate generation with human review
- Candidate → Validation → Commit pipeline
- Neo4j graph storage with PostgreSQL metadata layer
- Operator dashboard for pipeline management

**Stack:** Python · FastAPI · PostgreSQL · Neo4j · Next.js · Docker
